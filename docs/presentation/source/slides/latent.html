The HMM was fitted on the 11,183 training stays (435,449 hours) and converged in 25 iterations, 52 seconds. It never saw a sepsis label. One state stands out: heart rate about 102 and breathing about 22, which lines up with two of the SIRS criteria. Scoring uses the forward filter only, so hour t never looks at later hours. The signature captures the order in which vitals change, which plain rolling means miss. Results: NumPy logistic regression (K01), C = 0.3, fitted on train, calibrated on calibration, scored on the 3,051 validation stays (268 septic, 118,668 hours); 1,000 paired stay-level bootstrap resamples. We only say a feature helps if its 95% interval is above zero, and none is: the largest change is +0.0006 AUPRC. The shared features already include 3, 6 and 12 hour trends, which likely carry the same information. The added cost is small, so the HMM can stay as a readable trajectory view rather than as a performance claim; published work also found HMMs used alone are limited by how much patients differ. Tree models (K02, K03) might use these features differently; not tested here. MAP runs higher at hospital B, so the state probabilities may shift there.
