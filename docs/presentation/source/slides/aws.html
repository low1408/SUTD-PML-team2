Serverless design for ap-southeast-1 or ap-southeast-2, one CloudFormation stack per environment · icons: AWS Architecture Icons · 18

Top row: the hospital system sends a stay's history, signed with IAM, to the Lambda function URL. The scoring image loads the pinned model bundle from S3 and keeps only the alert ledger in DynamoDB. Middle row: GitHub Actions builds images tagged by commit into ECR; Step Functions runs prepare, tune and train as ECS Fargate tasks (Spot for the long steps), emails for approval, then runs the one frozen evaluation and a write-once publish. There are three image targets: scoring, Lambda and training. Alarms email the owner and retraining needs team approval. MLflow and Evidently run on ECS with a PostgreSQL database; a power workflow stops them when idle. The first SageMaker design is still in the code but no environment uses it. Before any real use, check data-residency and health-data rules in the hospital's country.
